# Сообщение коммита

1. Выполни `git diff --staged`. Если пусто — сообщи, что нет staged-изменений, и остановись.
2. Посмотри `git log --oneline -10`, чтобы повторить принятый в репозитории стиль и язык.
3. Определи тип: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `perf`, `build`, `ci`.
4. Сформируй сообщение:
   - заголовок `type(scope): кратко что сделано` — до 72 символов, без точки в конце;
   - пустая строка;
   - тело (если нужно): *почему* сделано изменение, а не пересказ диффа.
5. Покажи сообщение пользователю. Не коммить без явной просьбы.
